# Bharat Crypto

A responsive, single-page crypto education and market exploration site for an Indian audience. Built with plain HTML, CSS and JavaScript; no build step or package install is needed.

## Run locally

Open `index.html` in a browser. The main coin, charts, filters, FAQs, ticker, navigation, and newsletter preview are interactive.

## Publish with GitHub Pages

1. Upload the contents of this folder to the root of a GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch** and select the `main` branch and `/ (root)`.
3. Save. GitHub Pages will publish `index.html` from the repository root.

The `.nojekyll` file is included. All generated artwork is bundled locally. Google Fonts and creator thumbnails load from their source hosts, so those images and fonts need an internet connection. Market figures are illustrative samples and are not live exchange prices. The newsletter form is a front-end preview and does not save addresses.

## Files

- `index.html` — complete website and interaction code
- `bitcoin-coin.png` — gold coin artwork
- `trading-illustrations.png` — retained artwork from an earlier iteration
- `tools-illustrations.png` — toolkit illustrations
